### Qanday foydalanish?

* **UI** (React komponentlar) bu funksiyalarni `import { … } from '@/utils/…'` yoki `import { … } from '@/services/…'` tarzida chaqiradi.  
* **AI** funksiyalar (`ai.ts`) mantiqiy tarzda provayder tanlash (`getAIProvider`) ⇒ **Ollama** yoki **Gemini** ⇒ **prompt** yuborish ⇒ natija JSON → komponentga qaytarish.  
* **Supabase** servislar (`FlashcardService`, `TaskService`, `TelegramService`) barcha **CRUD** operatsiyalarini soddalashtiradi, shuningdek **link‑code** generatsiyasini ham qo‘llab‑quvvatlaydi.  
* **Gamification** (`gamification.ts`) va **Analytics** (`analytics.ts`) foydalanuvchi darajasi, mastery‑balli va statistikalarni hisoblab beradi, UI‑da “progress bar”, “level badge” va “insight” bildirishlar uchun ishlatiladi.  
* **NotificationManager** + **utils/notifications** birgalikda brauzer‑bildirishnomalari (desktop) va Telegram‑ishonchli bildirishnomalarini boshqaradi.
