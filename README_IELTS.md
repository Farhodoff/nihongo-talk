# IELTS Talk — Ingliz tili va IELTS Master Platformasi

Ushbu platforma CEFR (A1-C2) va IELTS imtihonlariga tayyorlanish uchun mustaqil ta'lim tizimi hisoblanadi.

## Imkoniyatlari:
1. **IELTS Writing Task 1 & Task 2**: Sun'iy intellekt orqali 4 ta mezon (TR, CC, LR, GRA) bo'yicha esse baholash.
2. **Grammatika (Murphy Grammar in Use)**: 100+ ta interaktiv grammatik mavzular.
3. **Cambridge IELTS Mock Exams**: Listening va Reading testlari.
4. **Speaking Coach**: IELTS speaking part 1, 2, 3 mavzulari bo'yicha AI bilan suhbat.
5. **Vocabulary Builder**: Academic va General IELTS so'zlari banki.

## Ishga tushirish:
```bash
npm install
npm run dev
```
